能被测量的一生

序 · 一间没有用处的房间

在《制造消费者》里，安东尼·加卢佐讲过一个细节。十九世纪的资产阶级判断一个人属于哪个阶层，不看他的收入，看他的房子。有独立厨房的比只有炉灶的高级，有餐厅的又高一档，能够再分出一间客厅的，几乎就站在了上层。一八八六年，阿尔伯特·巴博写过一段今天读起来相当冷酷的话，他说如今我们可以根据家里房间的数量来把人分类，住在连灶台都没有的单间里的是穷人，有做饭设施的大致是工人，有独立厨房的说明宽裕，再有餐厅就更高一级，若还有客厅，阶级地位便又上一层。

这段话之所以值得引用，不在于它势利，而在于它揭示了一种结构。阶层本来是一种看不见的关系，但它需要一个可以被外部核对的形式，才能在日常里起作用。房间的数量恰好提供了这个形式，它清清楚楚，可以数，可以比，可以在招待会上被来客当场评估。客厅在这个体系里是最后一块拼图，因为客厅没有实用功能，它唯一的用途就是被人看见。

法国学者黎欧拉·奥斯兰德分析过巴黎一户人家的摆设，说餐厅里摆着巨大的文艺复兴式餐边柜，角落里还有一架钢琴，而隔壁小屋放的是铁架床和仿路易十五的床头柜，这些都是小资产阶级住所的标志。在真正的上层人家，饭厅里不该有钢琴，铁架床只有仆人才用。这段话的意思并不是说摆设有品味高低，而是说摆设是一种语法，懂的人一眼就能读出主人的位置。摆错的人并非不努力，他只是没有掌握那套语法的细节。

从 LAMP 到前后端分离：架构演进与技术实践

LAMP 架构：传统 Web 开发的基石

在早期的 Web 开发领域，LAMP 架构犹如一座坚固的基石，支撑起无数动态网站的构建。LAMP，即 Linux + Apache + MySQL + PHP/Perl/Python，是一组开源软件的组合，它们协同工作，为 Web 应用提供了完整的运行环境。

随着移动互联网的迅猛发展，用户对于应用的体验和功能需求变得更加多样化和复杂。在这个背景下，传统的 LAMP 架构逐渐显得力不从心，其局限性愈发凸显，这也促使了前后端分离模式的诞生，成为 Web 开发领域的一次重要变革。
